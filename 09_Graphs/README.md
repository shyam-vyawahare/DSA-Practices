# Unit 09: Graphs

## Overview

This unit focuses on **Graphs**, one of the most important and versatile data structures in DSA.

Graphs are used to represent relationships and connections between entities. They are widely used in networks, maps, social platforms, recommendation systems, dependency management, and routing algorithms.

This unit builds graph knowledge from the fundamentals through **BFS, DFS, connected components, cycle detection, topological sorting, and shortest-path algorithms**.

---

## Objectives

By the end of this unit, you will be able to:

- Understand graph terminology and properties.
- Represent graphs using different techniques.
- Implement BFS and DFS.
- Detect connected components and cycles.
- Solve grid-based graph problems.
- Understand topological sorting.
- Apply shortest-path algorithms.
- Analyze graph algorithms using time and space complexity.
