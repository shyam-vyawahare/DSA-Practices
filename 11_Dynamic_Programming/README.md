# 🧠 Unit 11 - Dynamic Programming

Dynamic Programming (DP) is a problem-solving technique used to solve complex problems by breaking them into smaller subproblems, solving each subproblem once, and storing the results for future use.

This unit focuses on developing the ability to **recognize DP problems, define states, build transitions, and optimize solutions**.

---

## 🎯 Learning Objectives

By completing this unit, I aim to:

- Understand the fundamentals of Dynamic Programming
- Identify overlapping subproblems
- Understand optimal substructure
- Learn Top-Down DP using memoization
- Learn Bottom-Up DP using tabulation
- Convert recursive solutions into DP solutions
- Define DP states and transitions
- Solve 1D and 2D DP problems
- Understand subsequence-based DP
- Solve knapsack-style problems
- Optimize DP space complexity
- Recognize when DP is preferable to Greedy or Backtracking
- Develop strong DP problem-solving skills for technical interviews

---

## 🧩 What is Dynamic Programming?

Dynamic Programming solves problems by:

```text
Break the problem into smaller subproblems
              ↓
Solve each subproblem
              ↓
Store the result
              ↓
Reuse previously calculated results
              ↓
Build the final answer
```
