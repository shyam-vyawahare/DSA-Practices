# 🟢 Unit 10 — Greedy Algorithms

Greedy Algorithms solve problems by making the **best possible choice at each step**, with the expectation that these local optimal choices lead to a globally optimal solution.

This unit focuses on understanding when the greedy strategy works, how to identify greedy patterns, and how to prove or reason about greedy choices.

---

## 🎯 Learning Objectives

By completing this unit, I aim to:

- Understand the core idea behind Greedy Algorithms
- Identify problems where a greedy strategy can be applied
- Understand the greedy-choice property
- Learn how sorting enables greedy solutions
- Solve interval scheduling problems
- Work with reachability and resource allocation problems
- Understand greedy algorithms using two pointers
- Recognize situations where greedy fails
- Build confidence in explaining greedy solutions during technical interviews
