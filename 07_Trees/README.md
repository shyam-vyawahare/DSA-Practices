# Unit 07: Trees

## Overview

This unit focuses on **Binary Trees** and **Binary Search Trees (BSTs)**, two of the most fundamental non-linear data structures in Data Structures and Algorithms (DSA).

Trees are extensively used in technical interviews because they test recursion, traversal techniques, divide-and-conquer thinking, and efficient searching. This unit builds a strong foundation for advanced topics such as **Heaps**, **Trie**, **Segment Trees**, and **Graphs**.

---

## Objectives

By the end of this unit, you will be able to:

- Understand tree terminology and structure
- Implement and traverse binary trees
- Solve tree problems using DFS and BFS
- Work with Binary Search Trees (BST)
- Analyze recursive tree algorithms
- Solve common interview questions involving trees

## Time Complexities

| Operation | Binary Tree | Binary Search Tree (Average) |
|-----------|:-----------:|:----------------------------:|
| Search | O(n) | O(log n) |
| Insert | O(n) | O(log n) |
| Delete | O(n) | O(log n) |
| Traversal | O(n) | O(n) |

> **Note:** In the worst case, an unbalanced BST has O(n) search, insertion, and deletion time.
