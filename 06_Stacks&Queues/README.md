# Unit 06: Stacks & Queues

## Overview

This unit focuses on **Stacks** and **Queues**, two fundamental linear data structures that are widely used in algorithm design and technical interviews. You'll learn how these structures work, when to use them, and how to solve common interview problems using their underlying patterns.

---

## Objectives

By the end of this unit, you will be able to:

- Understand the LIFO and FIFO principles.
- Implement stacks and queues from scratch.
- Solve stack- and queue-based interview problems efficiently.
- Recognize and apply common patterns such as monotonic stacks and data structure simulation.
- Analyze the time and space complexity of stack and queue operations.

---

## Topics Covered

- Stack Basics
- Queue Basics
- Valid Parentheses
- Implement Queue using Stacks
- Implement Stack using Queues
- Min Stack
- Daily Temperatures (Monotonic Stack)

---

## Key Patterns

- Last In, First Out (LIFO)
- First In, First Out (FIFO)
- Monotonic Stack
- Auxiliary Stack
- Stack Simulation
- Queue Simulation

## Time Complexities

| Operation | Stack | Queue |
|----------|:-----:|:-----:|
| Push / Enqueue | O(1) | O(1) |
| Pop / Dequeue | O(1) | O(1) |
| Peek / Front | O(1) | O(1) |
| Is Empty | O(1) | O(1) |
